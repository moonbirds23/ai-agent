# 真实图生图 API

## 背景

当前 CogView-4 链路仅支持文生图。现有 RAG 是“参考图转文字后增强 Prompt”，不是真正把参考图片交给生图模型。

## 目标

接入支持参考图片输入的图生图服务，候选方向为腾讯混元生图，同时保留现有文生图能力和降级路径。

## 待确认

- 供应商、模型和 API 可用性。
- 图片输入数量、尺寸、格式和存储 URL 要求。
- `referenceMode` 如何映射到供应商参数。
- 文生图与图生图使用统一接口还是独立能力接口。
- 失败降级、费用控制、内容安全和结果保存策略。

## 下一步

完成 API 能力验证和最小调用实验后，再形成架构与实施任务书。
