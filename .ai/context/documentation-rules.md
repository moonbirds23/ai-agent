# 文档维护规则

状态：active

## 内容归属

- 当前项目事实、架构、操作指南：`docs/`
- AI 需求、执行计划、问题、交接：`.ai/`
- 可从代码生成的索引：`.ai/generated/`
- 本地日志、报告、运行数据：`var/`
- 工具自动发现的核心规则：根目录 `AGENTS.md`、`CLAUDE.md`

## 生命周期

- 新想法先进入 `requirements/`，不能直接写进 `AGENTS.md`。
- 方案确认后建立 `plans/active/` 任务书。
- 执行结果进入 `handoffs/`。
- 已完成或被替代的资料移入 `archive/YYYY-MM/`。
- 历史文档只用于追溯，不能作为当前实现依据。

## 索引原则

类名、接口、字段和包结构优先从代码生成，不手工长期维护。生成文件必须标注生成时间、对应 commit 和生成命令。
