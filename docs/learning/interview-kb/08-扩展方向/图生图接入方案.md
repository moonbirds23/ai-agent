# 图生图接入方案

## 现状

当前生图是 **图→文→图**：用户上传参考图 → LLM 看图 → 输出文字 imagePrompt → CogView 文生图。图片二进制从未到达生图 API。

## 要改的核心断点

```java
// ChatServiceImpl.handleGeneration() L240
ImageGenerationResult genResult = imageGenerationService.generate(
    aiResp.imagePrompt(),   // ★ 只有文字
    aiResp.style(),         // ★ 只有文字
    aiResp.dimensions()     // ★ 只有文字
);
// saved(GalleryPicture) 在作用域内但未被传入
```

接口签名：

```java
// ImageGenerationService.java
ImageGenerationResult generate(String prompt, String style, String dimensions);
// ★ 三个参数全是 String，无 image
```

## 改造方案

### ① 创建 ImageGenerationRequest

```java
public record ImageGenerationRequest(
    String prompt,
    String style,
    String dimensions,
    List<ReferenceImage> referenceImages  // ★ 新增
) {
    public record ReferenceImage(
        byte[] imageBytes,
        String imageFormat,
        Long galleryPictureId
    ) {}
}
```

### ② 扩 ImageGenerationService 接口

```java
// 新增方法（旧方法保留 default 桥接）
ImageGenerationResult generate(ImageGenerationRequest request);

default ImageGenerationResult generate(String prompt, String style, String dimensions) {
    return generate(new ImageGenerationRequest(prompt, style, dimensions, null));
}
```

### ③ ChatServiceImpl 传图

```java
private List<ReferenceImage> collectReferenceImages(ChatRequest request, GalleryPicture saved) {
    List<ReferenceImage> refs = new ArrayList<>();

    // 当前上传的参考图（autoSaveToCacheGallery 已入库，需 download 取回）
    if (saved != null) {
        byte[] bytes = galleryService.downloadPicture(saved.id());
        refs.add(new ReferenceImage(bytes, saved.picFormat(), saved.id()));
    }

    // Layer1 明确参考图（从图库下载）
    if (request.referencePictureIds() != null) {
        for (Long id : request.referencePictureIds()) {
            if (saved != null && saved.id().equals(id)) continue;  // 去重
            byte[] bytes = galleryService.downloadPicture(id);
            GalleryPicture pic = galleryService.getById(id);
            refs.add(new ReferenceImage(bytes, pic.picFormat(), pic.id()));
        }
    }
    return refs;
}
```

### ④ 新增混元实现

```java
@Service
@Primary
public class HunyuanImageGenerationService implements ImageGenerationService {
    @Override
    public ImageGenerationResult generate(ImageGenerationRequest request) {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("model", "hunyuan-image-v3");
        body.put("prompt", request.prompt());

        if (!request.referenceImages().isEmpty()) {
            var ref = request.referenceImages().get(0);
            body.put("reference_image",
                "data:image/" + ref.imageFormat() + ";base64,"
                + Base64.getEncoder().encodeToString(ref.imageBytes()));
        }

    }
}
```

## 图片来源与下载路径

| 图片来源 | 获取 bytes 的方式 | IO 次数 |
|---------|------------------|---------|
| 当前请求上传 | `autoSaveToCacheGallery` 解码后保留 bytes | 0（内存） |
| 当前请求上传（未优化） | `galleryService.downloadPicture(id)` | 1 次磁盘/网络 |
| Layer1 参考图（图库） | `galleryService.downloadPicture(id)` | 每次 1 次磁盘/网络 |
| 外部 URL | `imageDownloadService.download(url)` | 1 次网络请求 |

**优化**：让 `autoSaveToCacheGallery` 同时返回 bytes 和 GalleryPicture，避免刚写入又读回的重复 IO。
