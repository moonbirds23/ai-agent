# 面试 RAG 知识库

本目录是云图库 AI 图片生成助手项目的面试知识库，用于存储项目技术栈、架构设计决策、关键实现细节以及面试问答记录。

## 目录结构

```
interview-kb/
├── README.md                    # 本文件
├── 01-项目概览/                  # 项目定位、技术栈、环境配置
├── 02-架构设计/                  # 分层架构、数据流、核心设计模式
├── 03-RAG增强链路/               # 三层RAG、RAG系统性学习手册
├── 04-数据存储/                  # PostgreSQL/pgvector/Redis/对象存储/ChatMemory
├── 05-图片处理与生图/             # 图生文生图全链路、图生图扩展
├── 06-AI集成与SDK/              # Spring AI 1.0、智谱全链路、结构化输出
├── 07-异常与规范体系/             # ErrorCode、BusinessException、响应规范
├── 08-扩展方向/                  # 已规划的扩展点、架构预留
└── QA/                          # RAG 面试题库（26题）+ 索引
```

## 使用方式

1. **学习模式**：按目录顺序阅读，从概览到细节逐层深入
2. **面试模式**：说"面试问答"进入角色扮演，AI 作为面试官提问
3. **保存指令**：说"将 XXX 保存到 RAG 面试知识库"，AI 会将当前讨论的知识点写入对应目录
4. **QA 归档**：每次面试问答结束后，问答对自动保存到 QA/ 目录

## 维护原则

- 新增知识点 → 在对应分类下创建 `.md` 文件
- 发现问题/新增坑 → 更新已有文件，标注 `[更新: YYYY-MM-DD]`
- 原始访谈记录可以保留原始问答；`QA/` 标准题库按专业化、工程化规则整理
- 知识库内容面向面试场景，可包含架构图、代码片段、设计决策理由
- QA 标准答案优先采用主流工程实践，补充少量实用增强方案，并尽量引用官方文档、框架文档或经典论文
