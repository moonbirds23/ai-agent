# 技术栈全景

## 框架与语言

| 分类 | 技术 | 版本 | 选型理由 |
|------|------|------|----------|
| 基础框架 | Spring Boot | 3.5.14 | 企业级生态成熟，与 Picture-Backend 统一 |
| 语言 | Java | 21 | 虚拟线程、Record、Switch Expression、文本块 |
| 构建工具 | Maven | - | 与 Picture-Backend 一致 |
| AI 框架 | Spring AI | 1.0.0 GA (2025-05-20) | Spring 官方 AI 集成，ChatClient/ChatMemory/Advisor/VectorStore 开箱即用 |
| 速率限制 | 内存滑动窗口 (ConcurrentHashMap) | - | 按 IP+endpoint 60s 窗口，chat 10/min |

## AI 模型（全链路智谱）

| 用途 | 模型 | 调用方式 | 关键配置 |
|------|------|----------|----------|
| 文本生成 | `glm-4-flash` | Spring AI OpenAI Starter (base-url 指向智谱) | `spring.ai.openai.chat.options.model` |
| 视觉分析 | `glm-4.5v` | 同上 | `zhipu.vision.model` |
| 向量嵌入 | `embedding-2` | Spring AI EmbeddingClient | 维度 1024, 余弦距离 |
| 图片生成 | CogView-4 | REST API (RestTemplate) | `zhipu.image.api-key` |

**为什么全链路智谱？** 统一 API Key 管理、统一 base-url (`open.bigmodel.cn`)、中文生图能力国内领先。embedding-2 的 1024 维向量对中文语义效果优于 OpenAI text-embedding-ada-002。

## 数据存储

| 存储 | 技术 | 用途 |
|------|------|------|
| 关系数据库 | PostgreSQL | 图库元数据、AI画像、聊天消息历史 |
| 向量数据库 | pgvector (PostgreSQL 扩展) | 图片语义检索，IVFFlat 索引 + cosine_distance |
| 缓存 | Redis (Lettuce 客户端) | 会话记忆热层、消息 List 存储 |
| 数据库迁移 | Flyway | V1~V6 渐进式 DDL 迁移 |
| 对象存储 | 抽象接口 (local / COS 双实现) | 图片二进制文件存储 |

**为什么 pgvector 而非独立向量数据库？** 单体应用阶段，pgvector 与业务数据同库，减少运维复杂度。IVFFlat 索引在万级数据量下够用。后续可迁移到 Milvus/Qdrant。

## 环境约束

| 约束 | 说明 |
|------|------|
| 系统 JDK 1.8 | Maven 命令必须指定 `JAVA_HOME=path/to/jdk-21` |
| 端口 8231 | `server.port=8231`，context-path `/api` |
| API Key 不入库 | 通过环境变量 `ZHIPU_API_KEY` + `application-local.yml` (gitignored) |
| Git push 代理 | `git config --global http.proxy http://127.0.0.1:6234` |
| PostgreSQL 必须运行 | 本地开发需要 PG 运行 + 数据库 `ai_agent` 创建 |
