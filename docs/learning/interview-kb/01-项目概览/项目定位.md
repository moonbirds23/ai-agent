# 项目定位

## 一句话描述

云图库 AI 图片生成助手 —— 用户上传参考图或描述文字，AI 从图库中检索相似图片作为风格参考，生成符合需求的新图片。

## 核心能力

1. **智能生图**：用户描述需求 → RAG 检索图库参考 → LLM 优化 Prompt → 图片生成模型出图
2. **图库管理**：上传/导入/收藏/删除图片，自动 AI 画像分析，向量索引
3. **多模态对话**：支持纯文本、图片分析、图片生成三种模式
4. **风格模板**：10 套预设模板（水墨、赛博朋克、油画、素描、浮世绘、极简、复古、日系、水彩、电影感）

## 与 Picture-Backend 的关系

- 本项目后续将**迁移融合**到 `D:\code\java\Picture-Backend`
- 编码规范、异常体系、响应格式均对齐 Picture-Backend
- 当前作为独立服务运行，融合后作为 Picture-Backend 的 AI 模块
