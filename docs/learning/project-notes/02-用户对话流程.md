# 02 — 用户对话流程（mode=chat）

## 触发条件

`ChatRequest.mode = "chat"`，或旧版 `generationMode = false`。

## 完整数据流

```
用户发送 "你好，介绍一下你自己"
     │
     ▼
ChatController.chat()
  ├─ 生成/复用 chatId (UUID)
  └─ PictureApp.doChat(request, chatId)
         │
         ▼
    ① checkConversationLimit(chatId)
         └─ ChatHistoryRepository.countByConversation()
            超过 ChatMemoryProperties.maxConversationMessages (默认200) → 抛 BusinessException
         │
         ▼
    ② resolveMode() → MODE_CHAT
         │
         ▼
    ③ handleDiscussion(request, chatId)
         │
         ├─ autoSaveToCacheGallery(request)
         │    └─ 如果有图片base64 → GalleryService.upload() → StorageLocation.CACHE
         │       SHA-256 去重，重复图片返回已有记录
         │
         ├─ buildUserSpec(request, cachedPicture)
         │    └─ 构造 UserMessage:
         │       • text: request.message
         │       • media: 图库URL(已入库) 或 ByteArrayResource(直发base64)
         │
         ├─ ChatClient.prompt()
         │    ├─ .user(spec → text + media)
         │    ├─ .advisors(a → a.param("chatId", chatId))
         │    └─ .call().entity(outputConverter)
         │         │
         │         ▼
         │    Advisor 链执行:
         │      ContentGuard(0)        → 校验消息长度≤2000、无敏感词
         │      MessageChatMemory(内置) → retrieve_size=10, 取最近10条历史注入prompt
         │      PromptOptimize(20)     → 包装优化提示词
         │      Logging(30)           → 记录请求/响应/耗时
         │      ExceptionGuard(MAX)   → 兜底异常
         │         │
         │         ▼
         │    ChatModel.call() → glm-4-flash
         │      请求: system(角色定义 + JSON Schema) + user(历史 + 当前消息)
         │      响应: JSON → BeanOutputConverter → ImageAgentResponse
         │
         └─ ChatResponseVO.objToVo(imageAgentResponse, chatId)
              返回: { type:"chat", message:"我是云图库AI助手...", chatId }

    ④ ResultUtils.success(vo)
         → BaseResponse { code:0, data:ChatResponseVO, message:"ok" }
         → HTTP 200
```

## 关键参数

| 参数 | 值 | 原因 |
|------|-----|------|
| chat_memory_retrieve_size | 10 | 讨论模式不需要太多历史，10轮足够保持上下文 |
| 消息最大长度 | 2000 字符 | ContentGuard 限制，防止 token 浪费 |
| 会话最大消息数 | 200 | 防止单会话无限增长 |

## 与生成模式的区别

| | 讨论模式 | 生成模式 |
|------|---------|---------|
| RAG 增强 | ❌ 不走 | ✅ 三层 RAG |
| ChatMemory 截断 | 10条 | 50条 |
| RagInjection | ❌ 跳过 | ✅ 注入RAG文本 |
| 输出 | 纯文本 | 结构化生图参数 + 图片 |
