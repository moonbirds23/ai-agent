# 08 — 数据库设计

## 概述

PostgreSQL 17 + pgvector 插件。通过 Flyway 进行版本化 DDL 迁移。

## Flyway 迁移版本

| 版本 | 内容 | 创建的表 |
|------|------|---------|
| V1 | 初始 PG 迁移 | `gallery_picture`, `picture_ai_profile` |
| V2 | 向量存储 | `picture_vector_store` (pgvector) |
| V3 | 聊天历史 | `chat_message` |
| V4 | 存储位置 | `gallery_picture` 增加 `storage_location` 字段 |

## 表结构

### 1. gallery_picture — 图库图片元数据（24 字段）

```sql
CREATE TABLE gallery_picture (
    id              BIGSERIAL PRIMARY KEY,
    url             TEXT,              -- 图片访问URL (TEXT类型，智谱签名URL超长)
    thumbnail_url   TEXT,              -- 缩略图URL
    name            VARCHAR(255),      -- 图片名称
    introduction    TEXT,              -- 简介
    category        VARCHAR(100),      -- 分类
    tags            JSONB,             -- 标签数组 ["风景","建筑"]
    pic_size        BIGINT,            -- 文件大小(字节)
    pic_width       INT,               -- 宽度(px)
    pic_height      INT,               -- 高度(px)
    pic_scale       VARCHAR(10),      -- 比例
    pic_format      VARCHAR(10),      -- 格式(png/jpg/webp)
    user_id         BIGINT,           -- 用户ID(预留多用户)
    space_id        BIGINT,           -- 空间ID(预留)
    review_status   INT DEFAULT 0,    -- 审核状态
    pic_color       VARCHAR(50),      -- 主色调
    source_type     VARCHAR(20),      -- 来源(upload/url_import/generated)
    favorited       BOOLEAN DEFAULT FALSE,  -- 是否收藏
    storage_location VARCHAR(20) DEFAULT 'MAIN', -- 存储位置 MAIN/CACHE
    pic_hash        VARCHAR(64),      -- SHA-256 哈希(去重用)
    is_delete       INT DEFAULT 0,    -- 软删除标记
    create_time     TIMESTAMP DEFAULT NOW(),
    update_time     TIMESTAMP DEFAULT NOW()
);
```

**关键设计**：
- `url`/`thumbnail_url` 用 TEXT 而非 VARCHAR(255)：智谱 CogView 生成的签名 URL 极长，255 不够
- `tags` 用 JSONB：支持数组存储和 JSON 查询
- `pic_hash` SHA-256：上传时计算哈希，重复图片返回已有记录
- `storage_location`：MAIN=永久存储，CACHE=会话缓存（定时清理）
- 软删除：`is_delete=0` 过滤，不物理删除记录

### 2. picture_ai_profile — 图片 AI 画像

```sql
CREATE TABLE picture_ai_profile (
    picture_id      BIGINT PRIMARY KEY,  -- 关联 gallery_picture.id
    subject         TEXT,       -- 主体描述
    scene           TEXT,       -- 场景类型
    style           TEXT,       -- 艺术风格
    colors          TEXT,       -- 主色调
    composition     TEXT,       -- 构图方式
    lighting        TEXT,       -- 光影描述
    mood            TEXT,       -- 氛围情绪
    image_prompt    TEXT,       -- 可直接用于生图的提示词
    index_text      TEXT,       -- 拼接后用于向量化的文本
    vector_status   INT DEFAULT 0,  -- 0=待索引 1=已索引 -1=失败
    analyzed_at     TIMESTAMP   -- 分析时间
);
```

**关键设计**：
- 以 `picture_id` 为主键（一对一关联）
- `index_text` 是核心字段：拼接图库元数据 + 视觉分析结果，用于 Embedding
- `vector_status` 追踪向量索引状态，失败可重试

### 3. picture_vector_store — pgvector 向量存储

```sql
CREATE TABLE picture_vector_store (
    id          VARCHAR(36) PRIMARY KEY,   -- UUID (由 picture_id 确定性生成)
    content     TEXT,                      -- 原始文本(index_text)
    embedding   VECTOR(1024),              -- embedding-2 的 1024 维向量
    metadata    JSONB                      -- {"_pictureId": 123, ...}
);

CREATE INDEX ON picture_vector_store
    USING ivfflat (embedding vector_cosine_ops)
    WITH (lists = 100);
```

**关键设计**：
- `VECTOR(1024)`：智谱 embedding-2 的输出维度
- IVFFlat 索引 + cosine_distance：近似最近邻搜索，比全表扫描快 10-100 倍
- 确定性 UUID：`UUID.nameUUIDFromBytes("picture:" + pictureId)`，同一图片始终映射到同一 ID（幂等 upsert）
- `lists = 100`：分区数，`sqrt(row_count)` 的经验值

### 4. chat_message — 聊天历史（双层存储中的 PG 层）

```sql
CREATE TABLE chat_message (
    id              BIGSERIAL PRIMARY KEY,
    conversation_id VARCHAR(64) NOT NULL,   -- 会话 ID
    role            VARCHAR(20) NOT NULL,   -- user / assistant / system
    content         TEXT NOT NULL,          -- 消息文本
    image_refs      JSONB,                  -- [{"type":"GALLERY","pictureId":1}, ...]
    metadata        JSONB,                  -- 扩展元数据
    created_at      TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_chat_message_conv ON chat_message(conversation_id, created_at);
```

**关键设计**：
- `conversation_id` + `created_at` 复合索引：按会话分页查询
- `image_refs` JSONB：存储 `ImageRef` 数组（GALLERY 引用或 TEXT_DESCRIPTION）
- 异步写入（`CompletableFuture.runAsync()`），不阻塞 Redis 主路径

## 数据流关系

```
gallery_picture ──1:1──▶ picture_ai_profile ──向量化──▶ picture_vector_store
       │                        │
       │                        └─ index_text = 元数据 + 视觉分析结果
       │
       └─ pic_hash (SHA-256) → 去重
       └─ storage_location = MAIN | CACHE

chat_message (按 conversation_id 聚合，异步写入)
       │
       └─ image_refs → ImageRef { GALLERY | TEXT_DESCRIPTION }
```
