# 01 — 整体架构

## 项目定位

云图库 AI 图片生成助手。用户通过对话式交互，上传参考图或描述需求，AI 自动分析图片、检索相似图库图片、生成优化提示词，最终调用生图 API 产出图片。

## 技术栈

| 层次 | 技术 | 用途 |
|------|------|------|
| 框架 | Spring Boot 3.5.14 + Java 21 | 应用基础 |
| AI 编排 | Spring AI 1.0.0 GA | ChatClient / Advisor / ChatMemory / VectorStore |
| AI 模型 | 智谱全家桶 | glm-4-flash 文本 + glm-4.5v 视觉 + embedding-2 嵌入 + CogView-4 生图 |
| 数据库 | PostgreSQL 17 + pgvector | 图库元数据 + AI 画像 + 向量存储 + 聊天历史 |
| 缓存 | Redis 7 | 对话记忆热数据 |
| 存储 | 对象存储抽象 | local 文件存储（默认）/ COS 预留 |
| 迁移 | Flyway | V1-V4 版本化 DDL |
| 构建 | Maven | JDK 21 编译 |

## 分层规范（核心规则）

| 层 | 职责 | 返回类型 |
|----|------|----------|
| Controller | 只透传 + 包装 BaseResponse | `BaseResponse<VO>` |
| App/Service | 业务编排，AI 调用 | 裸 VO，不包装 |
| Advisor | 拦截增强（校验/记忆/注入/优化/日志/异常） | 链式调用 |
| Model/DTO | 请求数据契约 | Java record |
| Model/VO | 响应数据契约 | Java record |
| Common | 基础设施（BaseResponse, ResultUtils, ThrowUtils） | — |

## 关键设计决策

1. **HTTP 状态码始终 200**：业务状态在 JSON `code` 字段（0=成功，4xxxx=客户端错误，5xxxx=服务端错误）
2. **DTO/VO 全部用 Java record**：不可变、自动 Serializable、简洁
3. **BaseResponse 用 @Data**：框架层类，需要 @NoArgsConstructor 保证 Jackson 反序列化
4. **异常统一走 BusinessException**：不直接抛 RuntimeException，用 ThrowUtils.throwIf() 断言
5. **Advisor 不可变 Record**：修改 adviseContext 必须复制—修改—重建
