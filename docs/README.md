# 项目文档

这里保存描述“项目当前如何工作、为什么这样设计”的稳定知识，面向开发者和 AI。

## 目录

- `architecture/`：当前有效的系统架构与数据流
- `guides/`：启动、部署、调试、评测等操作指南
- `decisions/`：技术选型及不可从代码直接得出的决策理由
- `learning/`：项目学习笔记与面试知识库
- `assets/`：文档使用的图片等静态资源

实施计划、临时问题、代码审查和会话日志不放在这里，统一进入 `.ai/`。

## 收录标准

文档必须描述当前事实。已完成的实施方案、过时架构和一次性过程记录应归档到 `.ai/archive/`，不能继续作为当前架构依据。
