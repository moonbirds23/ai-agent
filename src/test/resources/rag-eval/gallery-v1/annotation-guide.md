# RAG评测标注指南

## 相关性分级（0-3）

对每个检索结果与查询的相关程度进行打分：

| 等级 | 含义 | 说明 |
|------|------|------|
| **3** | 高度相关 | 图片内容与查询高度吻合，应该排在前列。例如：查询"水墨山水" → 水墨山水画图片 |
| **2** | 相关 | 图片可作为生成参考，但不如等级3精准。例如：查询"水墨山水" → 水墨风格花鸟画 |
| **1** | 弱相关 | 图片与查询有微弱关联，但参考价值有限。例如：查询"水墨山水" → 中国风建筑插画 |
| **0** | 不相关 | 图片与查询完全无关，不应返回。例如：查询"水墨山水" → 科技产品宣传图 |

## 标注规范

1. 以用户查询意图为核心判断标准，不受图片名称/标签等元数据影响
2. 对同一查询的多张图片独立打分，互不影响
3. 等级3的图片应明显优于等级2的图片，以此类推
4. 如有歧义，偏向保守（取较低等级）
5. 不参与判断的图片不要标注（不会计入评测指标计算）

## 必排除图标注（mustNotReturn）

有些图片与查询存在表面关键词匹配但从业务角度绝对不应推荐，应放入 `mustNotReturn` 列表。
例如：查询"卡通风格"时，虽然某张PPT模板也含卡通元素，但它不是卡通风格生成参考。
